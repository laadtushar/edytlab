edytlab is a desktop audio editor you talk to. You describe an edit in chat, the assistant calls audio-editing tools on a branchable session graph, and you hear the result. It runs on Tauri 2 with a Rust backend and a React frontend, and works with your own key for Anthropic, OpenRouter, OpenAI, Groq or Gemini, with a local Ollama model, or with your ChatGPT plan (a preview).

These pages are for people who build on it or contribute to it. For the app itself (download, getting started, user guide, privacy), see [www.edytlab.com](https://www.edytlab.com). The source is at [github.com/laadtushar/edytlab](https://github.com/laadtushar/edytlab).
