# Website

Read before touching anything under `website/`.

- Separate Next.js 16 app, deliberately **outside** the pnpm workspace (so Vercel builds it standalone), with its own lockfile. The package is `edytlab-website`, so `pnpm --filter` does not reach it: `cd website && pnpm install --ignore-workspace`, then `pnpm test`, `pnpm typecheck`, `pnpm build`. `pnpm lint` calls `next lint`, which Next 16 removed — use `npx eslint .`.
- Animation is GSAP (`gsap`, `@gsap/react`); framer-motion is not installed. Components that animate need the `"use client"` directive, must respect `prefers-reduced-motion`, and must render their content visible without JavaScript.
- Demo videos: `website/lib/demos.ts` lists them, the files live in `website/public/demos/` (`<slug>.mp4` + `<slug>.jpg`), and `lib/demos.test.ts` fails if the list and the folder drift.
- Launch video and reels (`/videos`): `website/lib/videos.ts` lists them, and the files in `website/public/videos/` (`<slug>.mp4` + `<slug>.jpg`, plus `<slug>.vtt` for a 16:9 video's captions) are **copies** of the plain cuts under `marketing/` (the launch video and the reels; never a `*-narrated*` file, `audio/`, `sfx/`, `archive/` or the 1:1 cut: those carry ElevenLabs free-plan audio or repeat another cut). `lib/videos.test.ts` fails if a copy is not byte-identical (SHA-256) to its source, if the list and the folder drift, or if a `seconds`, `width` or `height` is not the file's own header; a re-cut in `marketing/` has to be copied over, its `.srt` converted (`lib/srt-to-vtt.ts`), its poster retaken (`posterAt`) and its `moments` (what happens, in order) brought in line with its cue file or `.srt`, which the test also holds. Each video has a page of its own, `/videos/<slug>`, where it is the one video on the page (Google indexes a video only when it is the main content of its page); `/videos` is a hub with no player, and a new video needs a `PAGE_UPDATED` date for its page. The site shows no video tied to an old release: the v0.7.0 promo cuts were taken off on 2026-10-25 (their sources stay in `marketing/promo-v0.7.0/out/`), and their old addresses redirect to `/videos` (`next.config.mjs` `redirects()`, pinned by `lib/redirects.test.ts`); retire a release video the same way rather than labelling it as old.
- `crates/tools/tests/website_tool_docs.rs` checks tool names and counts in the site copy, so a tool rename or a new tool needs the site updated in the same PR.
- Vercel deploys only `main` and branches with `website` in their name (`website/vercel.json` → `git.deploymentEnabled`, pinned by `lib/vercelConfig.test.ts`). The Hobby plan allows 100 deployments a day and counts every one Vercel creates, including those the `ignoreCommand` cancels, so app-only branches must not create any. Put `website` in the name of a branch that changes `website/` to get a preview. CI's `website (test)` job only tests and type-checks the site, so run `pnpm build` in `website/` yourself before merging a site change.
