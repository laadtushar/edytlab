Microsoft Visual C++ runtime
============================

The Windows installers of edytlab put these four files next to
edytlab-desktop.exe, in the folder edytlab is installed to:

  msvcp140.dll
  msvcp140_1.dll
  vcruntime140.dll
  vcruntime140_1.dll

They are the Microsoft Visual C++ runtime (version 14.40 or newer),
Copyright (c) Microsoft Corporation. ONNX Runtime (onnxruntime.dll, beside
them) needs them; edytlab itself is linked without them.

They are copied, unmodified, from the VC\Redist folder of the Visual Studio
that built this release. The Visual Studio license terms list that folder as
Distributable Code, and the files are distributed under those terms:

  Visual Studio license terms
  https://visualstudio.microsoft.com/license-terms/

  Distributable Code files for Visual Studio ("Visual C++ Runtime Files")
  https://learn.microsoft.com/en-us/visualstudio/releases/2026/redistribution
  https://learn.microsoft.com/en-us/visualstudio/releases/2022/redistribution

Microsoft's own installer for the same runtime, the Visual C++ Redistributable,
is at https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
